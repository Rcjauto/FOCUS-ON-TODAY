# 🎯 Focus on Today

A simple and responsive daily goal tracker built using **HTML, CSS, and JavaScript**.

The application helps users stay focused by allowing them to create and complete three daily goals while tracking their progress.

## ✨ Features

- ✅ Add up to 3 daily goals
- ✅ Mark goals as completed

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/focus-on-today.git
```

### 2. Open the project

Navigate to the project folder.

```bash
cd focus-on-today
```

### 3. Run

Simply open `index.html` in your browser.

No installation or dependencies required.

---

## 🎮 How to Use

1. Enter your daily goals.
2. Complete each goal by clicking the circle.
3. Watch the progress bar update automatically.
4. Finish all three goals to complete your day.
